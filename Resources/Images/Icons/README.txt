INSTRUCTIONS FOR EYE ICON:

1. Place your eyeball icon image file in this folder (Resources/Images/Icons/)
2. Name the file exactly: "eye_icon.png"
3. Recommended icon size: 25-30 pixels (width) x 20-25 pixels (height)
4. Supported formats: PNG, JPG, BMP, GIF

The icon will be used to toggle password visibility in the login form.
Click the icon to show/hide the password.

If the icon is not found, the eye icon will be hidden automatically.
